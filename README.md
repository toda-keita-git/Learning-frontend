# 目標達成支援アプリ（フロントエンド）

最終目標を設定し、それを達成するための **アクションプラン** に分解し、
学習用・タスク用・通常の3種類のメモで日々の取り組みを記録するアプリの **フロントエンド** です。
進捗（習熟度／進捗度）はメモからアクションプラン、アクションプランから目標へと自動集計されます。

> 🔗 バックエンド（Java / Spring Boot）：https://github.com/toda-keita-git/Learning-backend
>
> 元々は「学習ログ」アプリとして開発していたコードを `old/` に残しています。

---

## 📌 このアプリでできること

- **目標 → アクションプラン → メモ** の階層で、やることを明確化
- **アクションプランの優先順位付け**（ドラッグ&ドロップでの並べ替え）
- **メモの種類分け**：学習用（習熟度%）／タスク用（進捗度% + チェック付きtodo）／通常
- メモは未紐付けのまま作成し、**後からアクションプランに紐付け**可能
- アクションプラン単位の**振り返りタイムライン**
- 達成率の**自動集計**（メモ→アクションプラン→目標）
- カテゴリ／タグによる分類（既存資産を継承）

## 🛠 使用技術

| 分類 | 技術 |
|---|---|
| 言語 | TypeScript |
| フレームワーク | React 19 |
| ビルドツール | Vite |
| UI | MUI（Material UI） |
| ルーティング | React Router |
| API 通信 | axios |
| GitHub 連携 | @octokit/rest（GitHub API）＋ OAuth（ログイン基盤として継続利用） |

## 🏗 アーキテクチャ

```
[ブラウザ / React(この repo)]
        │  ① GitHub OAuth ログイン
        ▼
[GitHub]  ──認可コード──▶  [バックエンド / Spring Boot]
        │                        │ ② コード→アクセストークン交換
        │                        │ ③ 目標・アクションプラン・メモを DB(PostgreSQL) に保存
        ◀──────────データ─────────┘
```

- 認可コードからアクセストークンへの交換は、**Client Secret を漏らさないためにバックエンド側で実施**しています。
- データ本体は Spring Boot 経由で PostgreSQL に永続化します。

## 🚀 ローカルでの起動

```bash
# 1. 依存インストール
npm install

# 2. 環境変数を用意（.env.example をコピーして値を設定）
cp .env.example .env

# 3. 開発サーバ起動
npm run dev
```

必要な環境変数は [`.env.example`](./.env.example) を参照してください。

## 💡 制作の背景

当初は学習内容を記録するだけの「学習ログ」アプリとして開発していましたが、
記録して終わりになりがちで「わざわざ使いたくなる」決め手に欠けると判断し、
「目標を立て、アクションプランに分解し、日々のメモで積み上げる」アプリへ方針転換しました。
学習ログ時代に実装した GitHub 連携・OAuth 認証・状態管理の基盤はそのまま活かしつつ、
目標→アクションプラン→メモの階層構造と進捗の自動集計を新たに実装しています。
